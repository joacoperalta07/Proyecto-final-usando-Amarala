# Proyecto Final — Automatización con IA
### Ecosistema de Automatización IA para Gestión de Consultas — Amarala

**Alumno:** Joaquín Peralta  
**Comisión:** #96925  
**Curso:** Automatización con IA — Coderhouse

---

## Descripción

Sistema de automatización que clasifica y responde consultas de clientes de Amarala (productos personalizados en madera) de extremo a extremo. Integra n8n (orquestador), Airtable (base de datos), Claude API / Haiku 4.5 (IA) y Gmail (entrada y salida), con un punto de validación humana (HITL) antes de responder al cliente.
